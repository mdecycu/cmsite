Python

為了讓熟悉 C++ 或 Java 的用戶方便使用，在 Python 2.2 中，放入 @staticmethod (靜態方法) 裝飾器的用法，以便在類別 (Class) 中定義一個不需要存取類別屬性 (Class attributes) 或實例屬性 (Instance attributes) 的方法。本質上就是一個寫在類別內部的普通函式。

核心語法與特色

  1. 不綁定參數：普通方法需要 self，類別方法需要 cls，但靜態方法不需要這兩個參數。
  2. 呼叫方式：可以用 類別名稱.方法名稱() 直接呼叫，也可以透過實例呼叫 (但推薦用類別名稱)。
  3. 無法直接存取狀態：因為沒有 self 和 cls，它無法直接讀取或修改類別或實例的變數。
class Demo:
    @staticmethod
    def my_static_method(arg1, arg2):
        # 這裡只能使用傳入的參數 arg1 和 arg2
        return arg1 + arg2

範例：日期格式驗證器

假設要寫一個處理「員工（Employee）」資料的系統。需要一個功能來檢查使用者輸入的生日格式（字串）是否正確（例如必須是 YYYY-MM-DD）。這個檢查邏輯與特定的某個員工無關，只是一個純粹的工具函式，此時最適合用 @staticmethod：

from datetime import datetime

class Employee:
    def __init__(self, name, birthday_str):
        self.name = name
        
        # 在初始化時，呼叫靜態方法來驗證資料
        if Employee.validate_date(birthday_str):
            self.birthday = birthday_str
        else:
            raise ValueError("日期格式錯誤，必須是 YYYY-MM-DD")

    # 定義靜態方法
    @staticmethod
    def validate_date(date_text):
        """檢查字串是否符合 YYYY-MM-DD 格式"""
        try:
            datetime.strptime(date_text, '%Y-%m-%d')
            return True
        except ValueError:
            return False

# ===== 如何使用 =====

# 1. 無需建立實例，直接用「類別名稱」呼叫靜態方法來測試
is_valid = Employee.validate_date("2026-08-08")
print(f"格式是否正確: {is_valid}")  # 輸出: True

# 2. 正常建立實例（內部會自動呼叫該靜態方法）
emp = Employee("王小明", "1995-05-20")

# 3. 輸入錯誤格式，觸發錯誤
# emp_error = Employee("張三", "1995/05/20") # 這行會拋出 ValueError

什麼時候該用 @staticmethod？

當你發現某個方法符合以下條件時，就應該加上 @staticmethod：

  1. 邏輯相關性：這個方法的功能在邏輯上完全屬於這個類別（例如：屬於 Employee 類別的日期驗證，或是屬於 Math 類別的平方根計算）。
  2. 獨立性：方法內部完全不需要用到 self.variable 或 cls.variable。

其實 Python 語法允許將工具函式直接寫在檔案外層，那為什麼還要保留 @staticmethod 呢？主要原因有兩個：

程式碼封裝與命名空間（Namespace）：

如果這個工具函式只跟某個類別高度相關（例如前述的 validate_date 只服務於 Employee 類別），把它塞進類別內部作為 @staticmethod，可以避免污染外部的命名空間。開發者看到 Employee.validate_date() 就會立刻明白它的依賴關係。

支援繼承與多型（Polymorphism）：

寫在類別內部的靜態方法是可以被子類別繼承或覆寫（Override）的。如果是寫在檔案外層的獨立函式，就無法享受物件導向的繼承架構。

尼采的主張與對後代的影響

德國哲學家弗里德里希·威廉·尼采 (Wikipedia) 的核心主張包含上帝已死、超人與權力意志，並對後代的存在主義與後現代主義造成深遠影響。

尼采的主要主張

  1. 上帝已死 (God is dead)：認為科學與理性的發展，讓上帝不再是社會文化與道德的必要支柱。當絕對的真理與價值根源剝落，人類必須承擔創造意義的責任，而非因此陷入絕望。
  2. 權力意志 (The Will to Power)：主張生命本能的核心乃透過精神疆界的主動擴張 (Active Expansion) 與克服障礙 (Self-Overcoming & Overcoming Obstacles) 來創造力量，而非單純的求生存。
  3. 超人 (Overman)：超人乃指精神上的進化者，不是要宰制他人，而是徹底主宰自己的精神意志、生存苦難以及生命意義，在沒有上帝的荒涼世界中，獨自擔當起生命的立法者。
  4. 主人與奴隸道德 (Master–slave morality)：直斥基督教道德是平庸無能的弱者嫉妒卓越強者所產生的精神毒素；轉而全面推崇熱愛當下、活出自我生命力的主人道德。
  5. 永恆輪迴 (Eternal recurrence)：提出生命若要無數次重複發生，你是否能全然接受，甚至熱烈擁抱此一終極的生命考驗。

對後代的影響

  1. 催生存在主義：啟發沙特 (Wikipedia) 與卡繆 (Wikipedia) 等思想家，讓人們深入探討「生命本無意義，意義由自己賦予」的命題。
  2. 啟發後現代主義：解構客觀真理與大敘事，影響傅柯 (Wikipedia) 與德希達 (Wikipedia) 等人對權力與知識關係的批判。
  3. 文學與心理學：深刻影響佛洛伊德 (Wikipedia) 的心理分析、希特勒 (Wikipedia) 的扭曲誤讀，以及湯瑪斯·曼 (Wikipedia) 等文學家的創作。

尼采面對虛無主義並非消極逃避，也不是去尋找客觀的生命意義，而是主張透過主動跨越、重估價值與熱愛命運，將虛無轉化為自我超越的契機，親手將生命的意義創造出來。。

尼采對虛無主義的診斷

  1. 必然的階段：他認為虛無主義是西方宗教與絕對理性崩潰後，人類思想必經的「陣痛期」。
  2. 消極與積極：他區分了只會感到幻滅、絕望的「消極虛無主義」，與將其視為破壞舊體制、創造新價值契機的「積極虛無主義」。

尼采克服虛無主義的具體方式

  1. 重估一切價值：拒絕接受過去由宗教或外在世界設定的道德與意義，由每個人身為「主體」為自己重新定義價值。
  2. 發揮權力意志：將內在的生命本能與創造力完全釋放，透過不斷克服自身的軟弱與限制，在創造中感受生命的真實存在。
  3. 實踐超人精神：不依賴任何彼岸世界（如天堂），在沒有神、沒有絕對對錯的荒涼世界中，依然勇敢地成為自己命運的主人。
  4. 熱愛命運 (Amor Fati)：不僅是默默承受生命的一切痛苦與荒謬，而是張開雙臂全然擁抱、熱愛並肯定這僅有一次的現世生命。
  5. 通過永恆輪迴的考驗：如果生命中發生的每一件事（包括最痛苦的時刻）都將無數次重複，依然能毫不猶豫地說「我願意再活一次」，這就是對虛無主義的終極勝利。

尼采所主張 The Will to Power，主張生命本能的核心是主動擴張 (Active Expansion) 與克服障礙 (Self-Overcoming & Overcoming Obstacles) 來創造力量，而非單純的求生存。其具體的作為與生命狀態，可以透過以下四個層面來描述：

1. 自我超越與不斷克服（Self-Overcoming）

不求安穩，主動迎向痛苦：反對追求沒有痛苦的平庸幸福。他主張主動尋找挑戰與阻礙，並在克服困難的過程中，體驗自身力量的增長。

持續重塑自我：將自己視為一件尚未完成的藝術品。打破舊有的習慣、觀念與身份，不斷否定昨天的自己，以創造出更高版本的自我。

2. 價值的「重新評價」（Transvaluation of Values）

拒絕盲從傳統道德：不盲目接受社會、宗教或傳統所定義的「善」與「惡」。

獨立創造生命意義：在「上帝之死」的虛無主義危機中，不向命運低頭，而是以主動的姿態，為自己訂定新的生命法則與價值標準。

3. 將生命「藝術化」的創造性表達

釋放酒神精神（Dionysian）：承擔生命的殘酷與無常，仍能以強烈的熱情去擁抱生命、讚美生命。

強烈的風格化：將自己的生命力轉化為具體的創造活動，如寫作、藝術、哲學思考。讓擴張的力量成為實質的文化與精神產物，而非流於暴力的發泄。

4. 體現「超人」（Overman）的姿態

成為精神的立法者：不當隨波逐流的「末人」（The Last Man），而是成為給予世界意義的創造者。

絕對地肯定命運：面對「永恆輪迴」的極端考驗（如果人生要一模一樣地重來無數次），依然能熱愛自己的命運（Amor Fati），主動選擇並創造這樣的生命。尼采認為，一個僅僅「求生存」的人，過的是一種被動的、防禦性的生活；而一個「主動擴張與創造」的人，才是真正活出生命本能的強者。

物理定律是由空間、時間以及內部空間的對稱性原理所「決定」與衍生出來的產物。

-- 現代物理學的標準核心觀念

柏拉圖的《蒂邁歐篇》中被視為具體事實或得到現代科學印證的內容，主要包括將物質本質視為數學對稱性、物質與能量的守恆與轉換、時間與宇宙同時誕生的觀念，以及宇宙微調的「人擇原理」。此外，該書中關於亞特蘭提斯的描述，在考古學上普遍被認為是對聖托里尼火山爆發導致米諾斯文明毀滅的歷史記憶。

現代物理學的核心範式，將「物質的本質」徹底歸結為數學對稱性（尤其是群論與規範對稱）。物理定律不再只是描述現象的工具，而是由空間、時間以及內部空間的對稱性原理所「決定」與衍生出來的產物。

將物質本質視為數學對稱性核心概念

1. 對稱性決定物質與力不變性與守恆：

諾特定理（Noether's Theorem）證明，每一個連續的數學對稱性都對應大自然的一個物理守恆定律（例如時間平移對稱對應能量守恆）。

2. 規範場論（Gauge Theory）：

基本粒子之間的相互作用力（電磁力、弱力、強力）是由「局部規範對稱性」嚴格要求的結果；換言之，力是為了維持對稱性不變而必須存在的補償場。

將物質與力的本質視為「數學對稱性」，不僅可以解釋輻射傳遞能量的現象，更提供了目前物理學中最深刻、最本質的底層機制驗證。

在現代物理（量子場論與規範場論）的框架下，輻射傳遞能量（例如電磁波、光子傳播）正是「維持數學對稱性」的必然結果。

從以下三個層次可理解此一驗證與解釋：

一、 輻射是局部規範對稱性的必然產物

在經典物理中，電荷、電場、磁場和電磁波被當作既定的自然現象。但在對稱性的視角下，順序完全反了過來：因為宇宙要滿足某種數學對稱性，所以必須存在電磁輻射。

相位對稱性（U(1) 對稱性）：量子力學中，描述電子的波函數具有一個「相位」（Phase）。如果同時改變宇宙中所有電子的相位（全局對稱性），物理定律不變。

局部化（Local Gauge）的挑戰：如果希望物理定律在「不同時間、不同地點」各自改變相位也能保持不變（局部對稱性），數學上就會出現矛盾。

輻射（光子場）的誕生：為了修正這個矛盾，數學上必須強行引入一個全新的幾何場來「抵消」因地點不同而產生的偏差。這個為了補償、維持對稱性而誕生的場，就是電磁場（規範場）。

所以當電荷運動時，電磁場產生的波動（即電磁輻射、光子）在空間中傳播並帶走能量。之所以透過輻射傳遞能量，本質上是宇宙在跨越時空維持「U(1) 數學對稱性」的動態調整過程。

二、 輻射之所以能傳遞能量是時空對稱性的推論

輻射不僅僅是波，它還攜帶著實實在在的能量與動量。此現象可以用諾特定理（Noether's Theorem）得到最完美的對稱性解釋：

從時間平移對稱性推向能量守恆：物理定律在昨天、今天、明天都一樣，此一時間上的對稱性，在數學上可直接推導出「能量守恆」。

從空間平移對稱性推向動量守恆：物理定律在世界各地、甚至在月球上都一樣，這種空間上的對稱性，可推導出「動量守恆」。

當一個激發態的原子發射出輻射（光子）時，原子系統失去了能量與動量。根據對稱性要求的守恆定律，這些能量與動量絕對不會憑空消失，它們必須被賦予給這個維持對稱性的「規範場」（光子）。當輻射傳播並被另一個物體吸收時，能量與動量再次轉移。

因此，輻射傳遞能量的物理行為，正是時空對稱性（守恆）與內部對稱性（交互作用）交織運作的具體驗證。

三、 現代前沿：這如何改變我們對「能量與物質」的看法？

在傳統觀念中，我們會覺得「物質（如電子）是實體，它發出輻射（如光子）去傳遞能量給另一個實體」。

但在數學對稱性的理論中：

物質與輻射都是「幾何對稱性的激發態」。

電子是物質場的激發，光子是規範場的激發。

能量不是一種像液體一樣流動的物質，而是群論（Group Theory）變換中的一個「守恆不變量」。

輻射傳遞能量，就像是高維度幾何形狀在旋轉和扭曲時，為了保持整體的和諧與對稱，在不同時空點之間所進行的一種「數學記帳與平衡」。

人類所有思考所需的材料，都來自兩種經驗：一是對外在感官世界的觀察，二是對自己心智活動的反省。

-- John Locke

約翰·洛克 (John Locke) 的 "人類理解論"（An Essay Concerning Human Understanding, 1689年出版）是西洋哲學史上的經典巨著。這本書奠定了經驗主義（Empiricism）的基礎，主要探討人類知識的起源、性質、範圍以及限制。

洛克的核心理念可以拆解為以下四個主要面向：

一、拒絕天賦觀念 (Critique of Innate Ideas)

洛克在書中第一卷花費大量篇幅，強烈反駁笛卡兒等理性主義者所主張的「天賦觀念」(如上帝的概念、邏輯幾何公理是與生俱來的)。

  1. 白板說 (Tabula Rasa)：洛克認為人類的心靈在出生時就像一張「白紙」或「空白的黑板」，沒有任何預設的印記。
  2. 經驗的印記：大腦中所有的知識和觀念，都是在出生之後透過後天的經驗、學習和感官接觸才寫上去的。

二、觀念的起源 (The Origin of Ideas)

既然心靈是白紙，觀念從何而來？洛克認為只有兩個來源：

  1. 感官感覺 (Sensation)：我們透過眼睛、耳朵、皮膚等感官，接收外部世界的物理刺激 (如看到紅色、感覺到熱、嚐到甜味)。
  2. 心靈反省 (Reflection)：我們的大腦對內在活動的自省與覺察 (如思考、懷疑、相信、意願)。

洛克進一步將觀念分為兩類：

  1. 簡單觀念 (Simple Ideas)：被動接收、無法再分割的基礎元素 (如「黃色」、「冷」、「硬」)。
  2. 複合觀念 (Complex Ideas)：心靈主動將多個簡單觀念進行組合、比較或抽象化後產生的複雜概念 (如將「四條腿」、「毛茸茸」、「汪汪叫」組合成「狗」的概念)。

三、第一性質與第二性質 (Primary vs. Secondary Qualities)

為了全面解釋物體如何引發我們心靈中的觀念，洛克將物體的性質分為兩類：

  1. 第一性質 (主要性質)：物體本身客觀存在的物理屬性，不論有沒有人看見都不會改變。例如：形狀、體積、數量、運動或靜止。
  2. 第二性質 (次要性質)：物體本身不具備、而是透過其物理結構刺激我們的感官，在我們心靈中產生的客觀主觀感受。例如：顏色、聲音、味道、溫度 (「蘋果是紅的」其實是光線與眼睛互動後，在心中產生的第二性質)。

知識的範圍與限制 (The Limits of Knowledge)

洛克將知識定義為「心靈對我們觀念之間符合或不符合的知覺」。這意味著，我們無法直接認識客觀世界本體，只能認識由感官傳遞到大腦中的「觀念」。

  1. 實體 (Substance) 的不可知：洛克指出，我們雖然可以用「支持者」的概念來想像一定有一個物體本體支撐著這些性質，但我們永遠無法得知那個「實體」究竟是什麼 (這為後來的懷疑論埋下了伏筆)。
  2. 知識的等級：他將知識由高到低分為直覺知識 (最確定，如A=A)、論證知識 (需要推理，如數學證明) 和感性感知 (對外在世界存在的知覺，確定性最低)。
  3. 理性的界限：洛克提醒大腦的認知能力是有限的。人類不應該去追求超越經驗之外的形而上學空論 (如靈魂的物理結構)，而應該專注於對生活、科學和道德有實質幫助的實用知識。

雖然馬斯克沒有直接引用過洛克，但洛克的哲學論述 (特別是關於知識論與政治經濟學) 對馬斯克所處的現代科技創新環境、商業邏輯以及他的思維工具，有著極具代表性的間接影響與觀念呼應。這兩者之間的聯繫與思想碰撞可以從以下三個層面來解析：

一、第一性原理思維（First Principles Thinking）

  1. 馬斯克最著名的思維方法是「第一性原理」: 拒絕盲從類比（不因為別人這樣做，我們就這樣做），而是將事物拆解到最基本的真理，再從頭開始推導。
  2. 洛克"人類理解論"的呼應：這與洛克推翻天賦觀念、拆解知識的過程如出一徹。洛克把人類複雜的認知拆解為最底層、不可再分割的「簡單觀念」 (如物理性質)，再重新組合。共同點：兩者都強烈反對傳統權威與既定教條，主張從最根本的「基石」出發建構系統。

二、財產權、勞動理論與火星殖民

洛克在政治哲學 "政府論" 中提出著名的「勞動價值理論」 (Labor Theory of Value)：大自然原本是所有人共有的，但當人類付出了「勞動」將其開墾、加工，這份成果就合法轉化為個人的「私有財產」。

  1. 馬斯克的火星計劃 (SpaceX)：當馬斯克談及未來殖民火星時，最核心的挑戰之一就是「火星上的法律與經濟體制該如何運作」。火星是一片荒蕪的處女地，誰開墾、誰建造，誰就擁有產權。
  2. 影響與應用：現代西方資本主義對私有產權的保護，根基全部來自洛克。馬斯克之所以能憑藉私人企業推動太空探索 (這在過去是國家壟斷的)，完全得益於洛克所奠定的古典自由主義 (Classical Liberalism)與保護個人財產、合約精神的制度。

三、馬斯克更偏愛的哲學家

相較於英國經驗主義的洛克，馬斯克公開提及或受其影響更深的哲學思想其實是：

  1. 威廉·麥卡斯基爾 (William MacAskill) 與長期主義 (Longtermism)：這對馬斯克影響極大，促使他認為人類最重要的道德義務是確保意識的延續、防止AI滅絕人類或推動多行星生活。
  2. 尼采 (Friedrich Nietzsche)：馬斯克曾提過他年輕時讀過尼采，雖然當時覺得有些消極，但尼采關於「超人」和突破傳統道德框架的觀點，常被外界用來解讀馬斯克不顧一切打破常規的行事風格。
  3. 道格拉斯·亞當斯 (Douglas Adams) ：雖然是科幻作家（銀河便車指南），但馬斯克曾說這本書是他的思想啟蒙，教會他「提出正確的問題比尋找答案更難」。

PPE

PPE（Philosophy, Politics and Economics）

疫情期間的市場價格可能同時受到：

經濟基本面 + 投資人心理 + 市場情緒 + 群體行為 + 投機活動等因素影響。

經濟基本面，是指影響企業或整體經濟長期價值的各種實質因素。

對個別企業而言，基本面通常包括：

  1. 營收
  2. 淨利
  3. 每股盈餘（EPS）
  4. 現金流
  5. 負債
  6. 資產
  7. 股東權益
  8. 未來成長能力
  9. 企業競爭優勢

如果從總體經濟角度來看，則可能包括：

  1. GDP 經濟成長
  2. 利率
  3. 通貨膨脹
  4. 就業
  5. 工業生產
  6. 消費
  7. 投資
  8. 貨幣供給
  9. 政府政策

疫情期間出現的「群聚行為」（Herding

群聚行為是指投資人沒有完全依照自己的資訊與分析做決策，而是傾向於跟隨其他投資人的行動。

COVID-19 危機期間的印度股票市場出現了短期群聚行為（Short-term Herding）。

這代表投資人的決策在短期內可能受到其他市場參與者行為的影響，而不是完全根據自己的基本面分析。

這是一個非常重要的發現。

因為如果投資人都是理性的，應該根據：

  1. 公司財務狀況
  2. 企業未來獲利
  3. 股票合理價值
  4. 經濟環境
  5. 風險與報酬

來決定是否買賣股票。

但在危機期間，投資人可能受到：

  1. 恐慌
  2. 貪婪
  3. 害怕錯過行情 (FOMO, Fear Of Missing Out)
  4. 市場新聞
  5. 其他投資人的行為
  6. 社群與媒體資訊

影響。這表示市場價格可能短期偏離股票真正的基本價值。

疫情期間的「非理性投資」

研究進一步指出，COVID-19 危機期間，印度股市投資人的投資選擇具有一定程度的非理性（Irrationality）。

所謂非理性，並不是說投資人完全沒有理由，而是指投資決策不一定符合傳統金融理論所假設的「理性投資人」模式

理性投資人應該：

  1. 收集資訊
  2. 分析公司基本面
  3. 評估風險
  4. 計算合理價值
  5. 比較預期報酬
  6. 再決定是否投資

但在重大危機期間，人的心理可能會影響決策。

例如：

恐慌

看到股市大跌，就認為市場還會繼續下跌，因此不管股票真正價值，先賣出。

貪婪

看到某支股票快速上漲，擔心錯過機會，因此在高價追買。

羊群效應

看到別人買，就認為自己也應該買。

過度反應

市場出現一個負面消息，投資人可能過度解讀，造成股價跌幅超過基本面所合理支持的程度。

因此，疫情提供了一個非常特殊的研究環境，可以觀察投資人如何在極端不確定性下做出決策。

Datum

在 UGS NX3 中，建立基準面（Datum Plane）是構建三維空間幾何基準的最核心操作。NX 提供多種靈活的演算法，讓你能根據現有的點、線、面或角度來定位。

以下為最常用的 7 種建立基準面的操作步驟：

在開始以下任何一種方法前，請先執行：點選特徵工具列的 基準面 (Datum Plane) 圖示，或依序點選功能選單：插入 (Insert) -> 基準/座標系 (Datum/CSYS) -> 基準面 (Datum Plane)。

方法一：偏置基準面（Offset）

  1. 最常用，與現有平面保持特定垂直距離。
  2. 選擇類型：將對話框中的類型（Type）切換為 偏置 (Offset)。
  3. 選取參考面：點選現有的平整表面、既有基準面或座標平面（如 XY 平面）。
  4. 設定距離：在 距離 (Distance) 欄位輸入數值（例如：50mm）。
  5. 調整方向與數量：點選 反向 (Reverse Direction) 箭頭可切換偏置方向。調整 數量 (Number) 可一次建立多個等距離的平行面。
  6. 完成：點選 確定 (OK)。

方法二：成一角度（At an Angle / 傾斜面）

  1. 圍繞一條軸線旋轉特定角度，適合製作斜面或拔模基準。
  2. 選擇類型：切換為 成一角度 (At an Angle)。
  3. 選取旋轉軸：點選一條直線、實體邊緣或基準軸（作為旋轉的中心軸）。
  4. 選取參考面：點選一個與該軸平行的平面（作為計算 0 度的基準面）。
  5. 設定角度：在 角度 (Angle) 欄位輸入所需的角度值（例如：45度）。
  6. 完成：點選 確定 (OK)。

方法三：二等分面（Bisector / 中立面）

  1. 在兩個平行或成角度的平面正中間建立一個對稱面，極利於對稱零件建模。
  2. 選擇類型：切換為 二等分面 (Bisector)。
  3. 選取第一面：點選第一個平面。
  4. 選取第二面：點選第二個平行或相交的平面。
  5. 完成：系統會自動計算並將基準面精確定位在兩面正中央，點選 確定 (OK)。

方法四：通過三點（Through Three Points）

  1. 在非正交的任意空間中，利用三個不共線的點決定一個特殊平面。
  2. 選擇類型：切換為 通過三點 (Through Three Points)。
  3. 選取點：在 3D 空間中依序點選 點 1、點 2、點 3。
  4. 註：點可以是草圖頂點、實體角點、圓心或基準點。選取時可配合畫面上方的「點過濾器（Point Snap）」以精確捕捉。
  5. 完成：點選 確定 (OK)。

方法五：點和一條線（Point and Direction / 過點且垂直/平行）

  1. 通過一個特定點，並與某一條直線或向量垂直或平行。
  2. 選擇類型：切換為 點和方向 (Point and Direction) 或相關點線組合。
  3. 選取參考點：點選空間中的任意一個已知點。
  4. 選取直線/向量：點選一條實體邊、基準軸，或直接點選座標軸指定向量方向。設定幾何關係：在設定中選擇使平面 平行 (Parallel) 或 垂直 (Perpendicular) 於該線。
  5. 完成：點選 確定 (OK)。

方法六：相切於曲面（Tangent / 切面）

  1. 在圓柱面、圓錐面或任意曲面上建立一個相切的平面。
  2. 選擇類型：切換為 相切 (Tangent)。
  3. 選取曲面：點選圓柱體的外側曲面。
  4. 指定定位參考（可選）：若只選曲面，基準面可能會繞著圓柱轉動。此時可以再選一個空間平面，並指定「與其平行」或「與其成一角度」，來精確固定切面的方位。
  5. 完成：點選 確定 (OK)。

方法七：基於路徑（On Path / 曲線剖切面）

  1. 沿著一條曲線（如掃掠路徑）建立一個垂直於該曲線切線的平面，常用於建立掃掠（Sweep）的截面草圖。
  2. 選擇類型：切換為 基於路徑 (On Path)。
  3. 選取路徑曲線：點選一條草圖線、實體邊緣或不規則曲線。
  4. 設定位置（Location）：可以輸入 弧長（Arc Length） 或是 百分比（Percentage）。例如：輸入百分比 0 代表曲線起點；輸入 50 代表曲線正中央；輸入 100 代表曲線終點。也可以用滑鼠直接在畫面的曲線上拖曳黃色箭頭來決定位置。
  5. 完成：點選 確定 (OK)。

用上述任何一種方法建立好基準面後，不管它的預設方向為何，只要在啟動 草圖 (Sketch) 指令並點選該面時，在對話框中展開 草圖定向 (Sketch Orientation) 欄位，手動用 水平 (Horizontal) 參考去抓取空間中的絕對 X 軸、Y 軸或實體邊緣，就能完全主導草圖內部的 X-Y 軸方位。

參數驅動設計 (Parametric Driven Design)

參數驅動設計指幾何圖形的大小與形狀，由一組參數（數據、公式、幾何關係）來決定與控制。

UGS NX3 雖然無法像 NX9 之後的 Python Journal 程式驅動，但是 Tools - Expression 仍支援 .exp 尺寸及方程式輸出入的功能，若再加上 .exp 由 Python 程式進行控制，仍可達到一定程度的參數設計效能。

// 變數區分大小寫

[mm]p0=50
[mm]p1=0.0000
[mm]p2 = if (p0 <30) 50 else 100
//[mm]p2=p0*5
[mm]p0=7

// 參數全部讀取後再進行判斷式
// 與方程式的執行
// 且以最後設定的參數值為主
// 這是註解
// 透過 Tools - Expression import 後
// p0=7，p2=50

SS

Shape Studio (SS)

在 UG/NX3（2004 年發佈）中，Shape Studio（工業設計與造型模組） 是 Siemens 專為汽車外觀、消費性電子產品與高階工業設計所打造的「進階曲面造型利器」。SS 擺脫了傳統機械設計（如單純的拉伸、旋轉）的生硬感，核心特色是提供強大的 Class-A（A級曲面） 建立與分析工具，讓工程師能設計出極具流線感、滑順且符合美學的高難度曲面。

UGS NX3 Shape Studio 的 4 大核心特色

一、高階 A 級曲面建立功能 (Class-A Styling)

  1. 藝術曲面 (Studio Surface)：Shape Studio 的靈魂功能。可以同時限制多條截面導引線，並嚴格控制邊界處的曲面連續性（G0、G1、G2），是做出流線型外殼最常用的指令。
  2. 變形造型 (Global Shaping)：允許設計師像拉扯橡膠墊一樣，對一整塊現有的複雜 3D 模型進行整體的彎曲、拉伸或扭曲，適合用來做概念概念車身或人體工學滑鼠造形。

二、強大且嚴苛的曲面品質分析 (Surface Analysis)

在美學設計中，外觀微小的凹凸都會影響反光。Shape Studio 內建了當時最頂尖的檢測工具：

  1. 高光線分析 (Reflection Lines / Zebra Strips)：在曲面上投射虛擬的黑白斑馬線。如果斑馬線在曲面接縫處是斷開的，代表曲面不連續；如果線條平滑銜接，代表達到了頂級的 G2 曲面（曲率連續）。
  2. 曲率梳分析 (Curvature Combs)：用梳子狀的線條檢測曲線的平滑度。

三、混合建模 (Hybrid Modeling)

將「自由曲面（Freeform）」與「實體建模（Solid）」完美結合。設計者可以在 Shape Studio 裡用曲面切削實體，或是將多個曲面縫合（Sew）直接變成實體，不需要在不同的軟體間轉檔。

四、動態動態雕刻 (Dynamic Sculpting)

可以直接透過拖曳曲面上的 控制點（Control Points / Poles） 來微調曲面。讓工程師能像雕刻師一樣，憑直覺微調產品線條。

目前仍在服役的 Ender-3 列印機，是在 2019 年 3 月 5 日訂購，購買價是 220.99 美元。

眼看著目前流行的許多自動定位與多色列印款， Ender-3 可說是功能非常陽春的老古董，只是更換給料機構與列印噴頭後，仍舊堪用。

3D 列印最早從 1983 年 SLA (Stereolithography) 光固化列印開始，1988 前後發展出 SLS (Selective Laser Sintering) 到之後 SLM (Selective Laser Melting) 的突破，能在無支撐的條件下進行各種金屬零組件的列印，前後將近五十年。

全球第一台 SLS 原型機，是在 UT Austin 機械系中唯一的一間暗房中進行開發:

手電筒架設計

在親自動手做之前，覺得這個通用設計好像不錯，但覺得高度過低，而且組立時還需要兩條皮筋，有點麻煩。

因為整體的小手電筒並沒有很重，繞 Z 軸旋轉的功能只要整座提起即可，至於上下旋轉，也不需要使用球接頭做那樣複雜。直接利用兩端的夾片夾住四方體 (圓形體應該也行)，就可以自由調整上下旋轉的角度。

3D 列印時儘量讓所有物件平攤在熱板上，速度調慢約八成，PLA 噴頭的溫度調到 205 度 C，讓 Ender-3 慢慢印，大約一個多小時就可以完成。

3D 零件繪圖是採用 Solvespace 完成，任何人覺得原始設計的尺寸需要修改，可自己來。
