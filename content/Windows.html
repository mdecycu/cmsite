Windows

在 Windows 11 將 Edge 的搜索引擎換為 Google 後，Edge 仍然表現頑強，每次開起都會自動跳出由 MSN 精選的瀏覽內容，為了終止此一現象，可以修改 Windows 機碼（Registry），強制將 Microsoft Edge 瀏覽器的「新分頁（New Tab Page）」設為純白空白頁面，並關閉新分頁上的新聞、天氣與廣告內容。

其實並非不喜歡這類新聞、天氣與各種廣告內容，而是不很喜歡每次開啟 Edge 時，就會自動挑出這些被安排好的內容這件事。

首先以管理者身分開啟 Powershell，然後執行下列三段指令:

$registryPath = "HKLM:\SOFTWARE\Policies\Microsoft\Edge"
if (!(Test-Path $registryPath)) {
    New-Item -Path $registryPath -Force | Out-Null
}

Set-ItemProperty -Path $registryPath -Name "NewTabPageContentEnabled" -Value 0 -Type DWord

Set-ItemProperty -Path $registryPath -Name "NewTabPageLocation" -Value "about:blank" -Type String

各指令詳細功能解析:

$registryPath = "HKLM:\SOFTWARE\Policies\Microsoft\Edge"

功能：宣告一個變數 $registryPath，用來儲存 Edge 瀏覽器的系統原則（Policies）機碼路徑。

說明：HKLM: 指的是 HKEY_LOCAL_MACHINE，代表變更會套用到這台電腦上的所有使用者。

if (!(Test-Path $registryPath)) { New-Item -Path $registryPath -Force | Out-Null }

功能：確保機碼資料夾存在，若不存在則建立它。

細節說明：

Test-Path：檢查指定路徑是否存在（回傳 $true 或 $false）。

!：代表邏輯「非（Not）」，整句意思為「如果路徑不存在」。

New-Item -Force：強制建立該資料夾（機碼路徑）。

| Out-Null：將建立時產生的輸出訊息隱藏，保持畫面乾淨。

Set-ItemProperty -Path $registryPath -Name "NewTabPageContentEnabled" -Value 0 -Type DWord

功能：新增或修改名為 NewTabPageContentEnabled 的 DWORD (32-bit) 數值。

效果：設定為 0 表示關閉 Edge 新分頁上的 Microsoft Start 內容（如新聞 feeds、天氣、新聞卡片等）。

Set-ItemProperty -Path $registryPath -Name "NewTabPageLocation" -Value "about:blank" -Type String

功能：新增或修改名為 NewTabPageLocation 的字串（String）數值。

效果：將新分頁的網址強制導向 about:blank（純白空白頁）。
