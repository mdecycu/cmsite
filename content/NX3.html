NX3

NX3 是在 UGS 時代於 2004 年推出，所以也稱為 UG NX3 (Siemens 是在 2007 年 5 月才接手推出 Siemens NX6)，當時的 Windows 操作系統仍是 Windows 10 32 位元，至今無論是 NXOpen Journal 檔案存為 VB、C++ 或 Java 格式，在 2006 年 8 月都會因為缺少 20 年前的 .NET FrameWork 1.1 而無法執行，而採用 NXOpen C 編寫的延伸程式，由於記憶體的控管難度，也會讓 NXOpen C 的程式開發顯得困難重重。

由 Department of Mechanical and Aerospace Engineering, University of Missouri – Rolla 所建立的 UG-NX3-Tutorial.pdf

NX3/UGII目錄僅 600 MB 左右，加上 STEP203UG、STEP214UG、IGES 以及 ADMIN，總容量也還不到 700 MB，而且又可以採免安裝的設定方式執行，使用上非常方便。

NX3 不能使用中文進行目錄或檔案名稱存檔。

建立新檔案時，可以在左下方的單位選擇區，選擇使用 Inches 或 Milimeters 作為繪圖單位。

零件與組立檔案都使用 .prt 存檔，若要在開啟檔案前進行區別，可以在組立檔案的檔名中加上 _asm。

NX3 可以接受 STEP 203 與 214 格式的零件檔案 Import，必須先開新檔案後以 File - Import 功能導入。
