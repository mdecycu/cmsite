  2. 實體建構、建模操作、布林運算
  3. 網格剖分、STEP I/O、wgpu 渲染
  4. JavaScript／WebAssembly 整合方向

CAD Kernel 可支援多種幾何與實體表示方式，包括 B-rep（邊界表示法）、CSG（構造式實體幾何）、NURBS（曲線與曲面表示方式）、Mesh（網格表示法）、Implicit Surface（隱式曲面）、Voxel（體素表示法）及 Wireframe（線框表示法）。這些方式在分類層級與用途上有所不同，實際支援的類型則依 CAD Kernel 的設計而異。

其中可分類為:

  1. 幾何描述方式（例如 NURBS）
  2. 拓撲及實體表示方式（例如 B-rep、CSG）
  3. 離散化表示方式（例如 Mesh、Voxel）
  4. 線框及骨架表示方式 ( 例如 Wireframe、Curve Network )

更詳細的 CAD Kernel 幾何表示法分類:

一、幾何描述方式（Geometric Representation）

描述點、曲線、曲面及其數學形狀。

解析幾何（Analytic Geometry）：直線、圓、圓弧、平面、球面、圓柱面、圓錐面等。

NURBS（Non-Uniform Rational B-Splines）：以控制點、節點向量及權重描述曲線與曲面。

B-spline：以基底函數與控制點描述曲線、曲面。

Bezier Curve／Surface：使用 Bernstein 多項式與控制點描述曲線、曲面。

Subdivision Surface：透過細分控制網格生成平滑曲面，常見於自由造型。

Implicit Surface（隱式曲面）：利用隱式函數描述曲面，例如 f(x,y,z)=0 。

Parametric Surface（參數曲面）：以參數 u,v 描述曲面位置，例如 S(u,v) 。

二、拓撲及實體表示方式（Topology and Solid Representation）

描述物體如何組成、邊界如何連接，以及哪些區域構成實體。

B-rep（Boundary Representation，邊界表示法）：以頂點、邊、環、面、殼與實體等拓撲結構搭配幾何資料表示物體。

CSG（Constructive Solid Geometry，構造式實體幾何）：透過基本實體與聯集、交集、差集等運算組成物體。

Half-space Representation（半空間表示法）：以一組半空間的交集定義實體，常用於凸多面體及相關幾何演算法

Cell Decomposition（單元分解表示法）：將實體分解為多個單元，例如簡單實體或體積區域。

Boundary / Solid Hybrid Representation（混合表示法）：結合邊界表示與其他實體表示，例如以 B-rep 保存精確邊界，同時保留 CSG 或特徵運算資訊。

三、離散化表示方式（Discrete Representation）

將連續幾何或體積轉換為有限數量的離散資料。

Mesh（網格表示法）：以頂點、邊及三角形或多邊形描述表面。

Voxel（體素表示法）：以三維規則網格中的體素表示體積。

Point Cloud（點雲表示法）：以大量三維點描述掃描或取樣所得的形狀。

Tetrahedral Mesh（四面體網格）：以四面體單元離散化三維體積，常用於有限元素分析。

Hexahedral Mesh（六面體網格）：以六面體單元離散化體積，常用於工程模擬。

Octree（八叉樹表示法）：以階層式空間分割表示三維區域，可用於體素、碰撞及空間搜尋。

Signed Distance Field，SDF（有號距離場）：以空間位置到表面的有號距離表示形狀，常用於隱式建模與幾何處理。

四、線框及骨架表示方式（Wireframe and Skeleton Representation）

以線與點表示物體的骨架、輪廓或結構。

Wireframe（線框表示法）：以頂點與邊線描述幾何，不一定包含表面或封閉體積。

Curve Network（曲線網路）：由相互連接的曲線構成，可作為曲面生成、修剪或造型的依據。

Medial Axis／Skeleton（中軸／骨架）：描述形狀的內部骨架，可用於形狀分析、特徵辨識與部分建模流程。

五、設計意圖與建模歷史表示方式（Design Intent and Modeling History）

此類嚴格來說不是純粹的幾何表示法，而是 CAD 系統描述設計過程與可編輯性的方式。

Feature-based Representation（特徵式表示法）：以拉伸、旋轉、挖孔、圓角等特徵定義模型。

Parametric Representation（參數化表示法）：以尺寸、約束與參數控制幾何。

History-based / Procedural Representation（歷史式／程序式表示法）：保存建模操作及其依賴關係，讓模型能夠重新計算。

Constraint-based Representation（約束式表示法）：利用幾何約束與尺寸方程式定義草圖或幾何關係。
