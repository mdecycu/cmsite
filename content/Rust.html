Rust

在 Windows 11 建立採 NTFS 格式化隨身碟中的可攜式 Rust 程式開發環境，之所以要將隨身碟用 NTFS 格式化，是因為 cargo 快取只能存入 NTFS 格式區。

啟動可攜 Rust 程式環境的 start_rust.bat。

關閉可攜 Rust 程式環境則採用 stop_rust.bat。

可攜環境中的目錄配置:

data\

虛擬磁碟 Y: 的實際根目錄

.rustup\\ — Rust 工具鏈

.cargo\\ — Cargo 套件、設定及執行檔

mingw64\\ — MinGW-w64 編譯工具

portablegit\\ — Git

PuTTY\\ — SSH 工具

wscite\\ — SciTE 編輯器

home\\ — 使用者家目錄

projects\\ — Rust 專案

準備 Rustup 與 Rust

Rustup 用於管理 Rust 編譯器及工具鏈。

Cargo 則負責套件管理與建置。

Rust 官方下載頁面，下載 rustup-init.exe，安裝在 C:\使用者\帳號下\.cargo 以及 .rustup，安裝完成後將此兩個目錄複製到可攜套件的 data 目錄後，卸除 rustup-init 在操作系統安裝的 Rustup: the Rust toolchain installer。

接著從 https://www.msys2.org/ 下載 msys2-x86_64-20260927.exe，在 C:\msys64 安裝 Msys2。

C:\msys64 安裝完成後，執行 ucrt64.exe。

在 MSYS2 UCRT64 終端機執行:

pacman -Syu
pacman -S --needed mingw-w64-ucrt-x86_64-toolchain

輸入系統更新時會要求重新執行 ucrt64.exe，之後再執行 pacman -Syu 後，再執行 pacman -S --needed mingw-w64-ucrt-x86_64-toolchain，並選擇安裝全部內建套件。

可攜 Rust 建置完成後，可用來編譯 SolidCraft:

R:\projects>git clone https://github.com/tangency-labs/solidcraft.git

R:\projects>cd solidcraft

R:\projects\solidcraft>git checkout v0.21.0
Note: switching to 'v0.21.0'.

R:\projects\solidcraft>cargo run --release -p solidcraft -- --sample

利用 SciTE 開發 Rust 程式的兩個設定檔案:

rust.properties

SciTEUser.properties
