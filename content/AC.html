AC

Associated Copy (AC)

UGS NX3 允許使用者在 Part Navigator 中以滑鼠加上 Ctrl 選擇一個以上的 Features，然後再利用滑鼠帶出其中有 Group 的表單，利用此表單的 Group 可以將所選多個 Features 以群組名稱命名。

在 Part Navigator 中帶出的 Group 功能，等同 Format - Group Features，而非 Format - Group。

多個特徵群組後，可以用於 Insert - Associated Copy - Instance 中，所帶出的 Rectangular Array 或 Circular Array 進行 Pattern 複製。

Format - Group 功能的說明:

UGS NX 3 的 Format → Group 是一種持久性的模型物件組織機制，用於將一個或多個 NX objects 以指定名稱建立為邏輯群組，並將該群組顯示於 Model Navigator。Group membership 不改變成員物件本身的幾何、Feature dependency 或參數化歷史，其主要用途在於模型結構管理、工程語意分類及後續選取／管理。

先替一批 NX objects 建立一個有名稱的「可被重新找回、重新選取、重新管理的集合」，之後其他操作需要這批物件時，可以透過這個 Group 找回這批物件，而不必重新逐一選取。

在較為複雜的設計繪圖過程，可以透過將某些現階段不需要看到的定位面、特徵或圖素以 Format - Group 命名為特定群組，然後在  Part Navigator 中設定為顯示或不顯示，以提升在帶有多曲面與定位座標下的設計繪圖效率。
