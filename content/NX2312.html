NX2312

NX2312 包含 CAD/CAE 容量約 15GB

ugraf -nx 開啟 NX2312

NX_user.dpv 檔案格式:

採用 Python UTF-8 儲存 Journal 程式檔案:

<?xml version="1.0" encoding="UTF-8"?>

<?xml-stylesheet type="text/xsl" href="NX_user.xsl"?>
<PrefValues defaultLockStatus="unlocked">
<Pref Application="Gateway" Category="User Interface" Tab="Journal" displayValue="UTF-8" modified="2026-08-22T14:16:18" name="UG_journalFileFormat" title="Journal File Format" value="3"/>
<Pref Application="Gateway" Category="User Interface" Tab="Journal" displayValue="Python" modified="2026-08-22T14:16:18" name="UG_journalLanguage" title="Journal Language" value="4"/>
</PrefValues>

因為 NX3 無法處理 STL 格式的零件，但可以採 NX2312 處理:

在 NX2312 導入 STL 必須先開一個 new Model file 之後再使用 File - Import - STL 導入所需的 STL 格式零件。

導入的 Facet Body Output Type 有三個選項，分別是 Convergent、NX 以及 JT。若是要延伸其中特定 Face，選擇以 Convergent 導入。

導入後利用 Application - Shape Studio - Polygon Modeling 選擇要分割 Face 的 Facet Body，接著使用 Divide Facet Face，將希望改變厚度尺寸的面與 Facet Body 進行分割，之後再使用 Offset Face 進行增厚或變薄的操作。

若將所導入的 Convergent Body Facet 的所有面均予以 Divide Facet Face，之後就可以進行後續的 Edge Blend 操作。
