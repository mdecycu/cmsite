PP

利用舊版的可攜 Python 建立 Portable Python 3.15.0。

在 Scite 環境中執行下列 Python 程式:

gen_portable_python315.py

接著修改舊版啟動可攜 Python 的批次檔案，將舊版路徑換為新版 Python 3.15.0 所在路徑。

最後再利用 cmd 執行 python get-pip.py:

https://bootstrap.pypa.io/get-pip.py 

可攜系統有 pip 之後，再安裝 cms 所需模組:

pip install flask flask_cors bs4 lxml pelican markdown

目前 cmsimde 已經改名為 cms，因此原先採 cms 批次檔案啟動的指令，改為 scms。

另外，由於 Webots 2023b 與 NX2512 所使用的 Python 版本為 3.12，因此在 Python 3.15.0 環境下，無法使用 NX2512 的動態連結程式庫進行二次開發，必須退回 Python 3.12 可攜版本才行。

以下為 Python 3.15.0 的可攜啟動批次檔案， Webots 2023b 與 NX2512 仍然可以配合啟動執行。

start_python315.bat
