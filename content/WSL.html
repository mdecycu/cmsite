WSL

以管理者身分啟動 Powershell

# 修正 PowerShell 亂碼與空格問題
[console]::OutputEncoding = [System.Text.Encoding]::Unicode

# 清除可能殘留的舊版本環境
wsl --unregister Ubuntu
wsl --unregister Ubuntu-22.04

# 強制繞過微軟商店，從網頁直接抓取最穩定的 Ubuntu 22.04 LTS
wsl --install --web-download -d Ubuntu-22.04

設定 Linux 帳號與密碼

# 1. 更新並升級 Linux 核心元件 (中途若跳出詢問請一律打 y 按 Enter)
sudo apt update && sudo apt upgrade -y

# 2. 安裝 Linux 標配的 C 語言編譯與鏈結器工具鏈 (Mojo 打包成 my_app 必備)
sudo apt install build-essential -y

# 3. 一鍵安裝新世代 Pixi 套件管理器
curl -fsSL https://pixi.sh/install.sh | bash

# 4. 刷新終端機設定，讓 Pixi 變數立即生效
source ~/.bashrc

# 5. 使用 Pixi 同時指向開源與官方最新管道，全域安裝 Mojo 1.0.0 穩定版
pixi global install mojo -c conda-forge -c https://modular.com

建立測試專案:

mkdir -p ~/projects/hello_mojo && cd ~/projects/hello_mojo
nano main.mojo

main.mojo 內容:

# 1.0.0 正式版官方唯一標準：Python 互操作性元件已被移至 std.python
from std.python import Python 

def main() raises:
    print("Mojo 1.0.0 核心引擎啟動成功！")
    
    # 1.0.0 規範：新宣告變數必須強制加上 var 關鍵字
    var a = 100
    var b = 200
    print("Mojo 高性能整數加總結果:", a + b)
    
    # 透過標準庫的 Python 生態動態引入 sys 模組
    var sys = Python.import_module("sys")
    print("目前 CPython 虛擬機運行的版本為:", sys.version)

離開編輯器方法： 貼上後，按下鍵盤的 Ctrl + O 再按一次 Enter（儲存檔案），接著按下 Ctrl + X（離開編輯器）。

最後完成編譯:

# 執行靜態編譯與鏈結，打包成 my_app
mojo build main.mojo -o my_app

# 脫離 Python 依賴，直接以系統級原生速度執行！
./my_app

從 Powershell 進入 WSL 中的 Ubuntu 22.04:

wsl -d Ubuntu-22.04 -u username
